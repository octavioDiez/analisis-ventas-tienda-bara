# Análisis de ventas de la tienda

Proyecto de análisis de ventas, cortes de caja y faltantes basado en reportes
de una tienda. El análisis por producto compara tres mantecadas Bonamark
con historial de ventas del 9 al 26 de octubre de 2026.

## Cómo ejecutar el proyecto

1. Descarga `analisis_ventas_colab.ipynb` y `ventas_tienda.sqlite`.
2. Abre el notebook en Google Colab.
3. Ejecuta la primera celda y selecciona `ventas_tienda.sqlite`.
4. Ejecuta las demás celdas en orden.

## Resultado principal

La mantecada de chocolate lideró entre los tres productos observados,
con 55 unidades netas vendidas en el periodo comparado.
